## Freelancer Management System ##

## 📌 Project Overview

The **Freelancer Management System** is a web-based application developed as part of the IMS566 (Advanced Web Design Development and Content Management) course.

This system is designed to help users efficiently manage freelancer-related information, including viewing data, monitoring activities, and accessing a centralized dashboard.

The application demonstrates the implementation of modern web design principles, responsive layout techniques, and structured content management.



## 🎯 Objectives

The main objectives of this project are:

* To design a functional and user-friendly web application interface
* To apply responsive web design using modern frameworks
* To implement structured navigation and content organization
* To simulate authentication functionality without a database
* To present data clearly using tables and visualisation tools



## ✨ Key Features

### 🔐 1. Authentication System (Simulated)

* Login interface with username and password input
* Error message for invalid credentials
* Authentication is simulated using hardcoded values (no database required)



### 📊 2. Dashboard Page

* Displays a summary of system data
* Includes visual elements such as charts/graphs
* Provides quick overview for users after login



### 📁 3. Data View Pages

The system includes multiple data display pages:

* Freelancer List Page
* Task/Project Management Page (or any dataset used)

Features:

* Data presented in structured tables
* Clean and readable layout
* Organized information hierarchy



### 🧭 4. Navigation Menu

* Consistent navigation bar across all pages
* Easy access to all system features
* Responsive design for both desktop and mobile devices



### 📈 5. Data Visualisation

* Integration of chart/graph using Chart.js (or your library)
* Visual representation of meaningful data (not random)
* Enhances user understanding of system information



### 📱 6. Responsive Design

* Fully responsive layout
* Compatible with desktop, tablet, and mobile devices
* Built using modern CSS framework
